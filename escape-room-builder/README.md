# Escape Room Builder inside Chip In ToolBox

This is a **self-contained copy** of Escape Room Builder V10, imported from `ChipButt/Escape-Room-Puzzles` on 23 November 2026 (source commit `0f433f2d5a06240f3b35cb9af5e0ae4e5a97fd09`).

Open `/escape-room-builder/` from the ToolBox homepage. All runtime HTML, CSS, JavaScript and artwork are stored under this directory in the ToolBox repository; the tool does not redirect or iframe the external Escape Room Builder website.

Includes Stone Lock, Stone Wheel, Stone Logic, Stone Buttons, Escape Door, and Wall Safe. Save/load and playtest operations remain local in the browser. The original repository remains separate; later changes must be deliberately copied if parity is desired.

The back navigation in the builder returns to `../` (ToolBox).
