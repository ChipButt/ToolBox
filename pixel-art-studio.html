Export

PNG exports use a genuine alpha channel. Empty pixels are transparent; the checkerboard is only the editor background.

Code format

The GameBox export stores a palette plus horizontal pixel runs for every frame and includes a renderer that builds a GBPixel.Grid. It can be animated with no PNG files.

Ctrl/Cmd+Z = undo · Ctrl/Cmd+Y = redo · Ctrl/Cmd+C/X/V = selection · Delete = clear selection · D = duplicate frame · Space = play/pause
